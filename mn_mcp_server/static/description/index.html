MCP = MODEL CONTEXT PROTOCOL

The open standard for connecting AI to live data.

This module exposes Odoo as an MCP server at POST /mcp. Any MCP client (Claude, Cursor, custom agents) authenticates and can safely read & write your Odoo — Sales, CRM, Inventory, Accounting, custom models — bounded by per-key scopes, permission flags and Odoo’s standard ACL.

★ SCOPED API KEYS

FIVE-MINUTE QUICKSTART

Connect Claude in five minutes.

1. Install mn_mcp_server.
2. MCP Server → API Keys → New. Pick the Odoo user, choose the models, tick the permissions you want.
3. Open the Connect to Claude tab & copy the URL (your key is already in it).
4. In Claude → Settings → Connectors → Add custom connector → paste the URL → Add. (Your Odoo must be reachable over https.)
5. Ask: “Find my top 5 customers by revenue this month.”

Prefer the config-file route? A ready claude_desktop_config.json snippet and an mcp-remote command are on the same tab — they even work over http.
